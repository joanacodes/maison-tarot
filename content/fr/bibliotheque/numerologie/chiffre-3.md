## Ce que dit le 3 {#definition}

**Le 3, c’est cadence.** Machine lancée, contrat qui fonctionne, fratrie en bons termes. Le 3 est la cadence trouvée : ça marche, et ça se voit. Dans le [cycle des nombres](/fr/bibliotheque/numerologie/), il vient après le 2 et prépare le 4.

## Le conseil du 3 {#conseil}

S’assurer de terminer un projet avant d’en commencer un autre. Le 3 donne de l’élan ; l’élan donne des idées ; les idées dispersent.

## Un exemple que tout le monde connaît {#exemple}

Le lancement d’Instagram marche. Les gens s’inscrivent, postent, reviennent. Rien n’est encore gagné (voir le 5), mais pour la première fois la chose tourne sans qu’on la pousse. Le fil rouge de toute cette section est l’histoire d’Instagram, du [1](/fr/bibliotheque/numerologie/chiffre-1/) au 10 : vous en connaissez la fin, alors vous voyez le cycle.

## Les cinq cartes qui portent le 3 {#cartes}

Vous n’avez pas à les mémoriser. Le nombre dit l’étape ; l’[élément](/fr/bibliotheque/quatre-elements/) dit le plan sur lequel elle se joue.

- [L’Impératrice](/fr/bibliotheque/cartes-tarot/l-imperatrice/) — arcane majeur 3.
- [Trois de Bâtons](/fr/bibliotheque/cartes-tarot/trois-de-batons/) — 3 + Feu.
- [Trois de Coupes](/fr/bibliotheque/cartes-tarot/trois-de-coupes/) — 3 + Eau.
- [Trois de Épées](/fr/bibliotheque/cartes-tarot/trois-de-epees/) — 3 + Air.
- [Trois de Pentacles](/fr/bibliotheque/cartes-tarot/trois-de-pentacles/) — 3 + Terre.

## En lecture {#lecture}

Un 3 dans un tirage dit : **ça fonctionne, et c’est visible.** Le Trois de Coupes fête, le Trois de Pentacles construit à plusieurs, le Trois de Bâtons regarde ses bateaux partir, le Trois d’Épées — le seul 3 douloureux — montre que quand trois cœurs sont en jeu, la cadence peut aussi se rompre. L’Impératrice est le 3 qui produit : la fertilité, au sens le plus large.
